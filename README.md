## 🚀 Featured Project: [BreachMark](https://github.com/VarshSec/breachmark)

<p align="center">
  <a href="https://github.com/VarshSec/breachmark">

**A benchmark for breach-grade bugs.** BreachMark tests whether large language models can actually tell vulnerable code from safe code. Each model is shown **1,396 real vulnerabilities** from open-source projects (Linux kernel, Mozilla, Xen, plus the SVEN dataset) — once as the vulnerable version and once as the patched version — and the results are turned into standings, confusion matrices, per-CWE heatmaps and exportable reports.

- 🤖 Works with **Ollama, OpenAI, Anthropic** and any OpenAI-compatible server
- 📊 Accuracy with confidence intervals, recall, specificity, F1, latency and cost
- 🧠 4 prompt strategies + **blind mode** that hides the CWE hint
- 🔁 Resumable async runner with retries, pause/cancel and a circuit breaker
- 🧪 59 automated tests, Docker support, CLI and web dashboard
